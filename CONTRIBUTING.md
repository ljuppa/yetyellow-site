# Contributing

This is a personal site. Contributions and changes should remain narrow, factual and easy to review.

## Working agreement

- `main` is always deployable.
- Use short-lived branches: `feat/...`, `fix/...` or `chore/...`.
- Keep one intent per pull request.
- Update documentation when a change alters an agreed product, architecture or delivery decision.
- Do not publish credentials, personal contact details beyond the intended public contact route, employer-confidential material or unverified claims.

## Before merge

Run formatting, type checks, tests and the production build once the implementation exists. Review the deployment preview before merging to `main`.
